# Set your DeepSeek API key

1. Open [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys)
2. Create an API key and copy it
3. Run **DeepSeek: Set API Key** and paste the key

Your key is stored in VS Code SecretStorage (macOS Keychain, Windows Credential
Manager, or Linux libsecret) and is only ever sent to `api.deepseek.com` —
no analytics, telemetry, or third-party services.
